# JMI EMC 修正箇所マップ

スプレッドシートの修正コメントを、JMI EMC第37期の開講レポートとインタビュー上に番号・赤い下線・写真枠で表示する確認用サイトです。

- 「修正前」「修正後」で文言を比較できます。
- `lp.html` に参照サイトのTOPページを再現し、その中にインタビューと開講レポートの一覧を配置しています。
- 記事ページの「Report」から、TOPページ内の開催レポートへ移動できます。
- レポートとインタビューは、ページ内のリンクから相互に移動できます。
- 各ページのA・B番号は、2026年8月2日・8月3日の指摘に対応します。
- GitHub Pagesで公開する静的HTMLです。
